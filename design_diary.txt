Stage: Secondary UDP Monitoring Channel & Stream Lifecycle (MONITOR START/STOP)

Key Decisions Made:
1. UDP Architecture:
   - Created a dedicated POSIX thread (udp_monitor_thread) triggered by MONITOR START.
   - Used SOCK_DGRAM UDP sockets transmitting lightweight metric datagrams to the 
     Controller IP on the dynamically specified target UDP port.
   - Paced datagram interval at 2.0 seconds with responsive sub-interval polling to 
     allow instant cancellation without blocking.

2. State Management & Teardown:
   - Designed atomic cancellation flag (volatile int running) to gracefully terminate 
     the telemetry thread on MONITOR STOP or client disconnect.
   - Ensured all UDP datagrams append the mandatory reversed session tag 'SID:5133'.
